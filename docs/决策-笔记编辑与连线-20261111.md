## 二、编辑交互（照 Obsidian / Notion）

1. 单击选中 → **双击原地编辑**（多行 TextField 自适应高度）。
   - Esc 取消；Ctrl+Enter 或失焦保存。
2. 自动保存：失焦立即存；输入停顿 800ms 兜底存。
3. 顶部三态：`编辑中 / 保存中 / 已保存 hh:mm`；失败显示 `未保存 · 重试`，不许静默。
4. 每次写入走 **写前备份 + 回读校验**；回读不一致回滚并报错。
5. 标题单行、正文多行，分开存。
   - 同时修 `pages.dart L713 / L732` 标题重复渲染：抬头一次，正文区渲染 `body`。

## 三、自由连线（照 Excalidraw / tldraw）

1. 交互：节点 hover / focus 时四边中点浮出 handle；从 handle 拖出 → 目标高亮 → 松开成边；松在空白 = 取消，不留半个绑定。
2. 键盘等价：选中节点 A → `L` 进连线模式 → 方向键选目标 → Enter 确认 → Esc 取消。
3. 边的生命周期（必须全做）：
   - 删节点 → 级联删所有关联边；
   - 移动 / 改尺寸 → 端点按 rect 重算（现行 `_CanvasEdgePainter` 已按 rect，保持）；
   - 切页 / 切视图 → 清空临时线与选中态（与 tooltip / 幽灵卡同族回归）；
   - 创建前校验：不许自连、不许重复边（同 from→to）。
4. 边可编辑：右键 / 键盘 `E` → 改标签、换方向、删除；跨分组边不静默丢弃，虚线画。
