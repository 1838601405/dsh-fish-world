# P0 · 戳头像落对话：桥缺口（2026-11-11）

## 现状

- `AvatarTap._tap` → `sayFeedbackAsync` → `bridgeFeedback` 只拿一句反馈，
  进侧栏气泡；`ChatPanel` 的 `_messages` 是本地初始化列表。
- 桥现有的 `/api/chat` 是「发历史 → 回一句」，没有「把一条 assistant 消息追加进
  DSH 当前会话」的写接口。
- `ChatPanel` 也没有持久化，刷新后本地消息本来就不在。

## 缺的接口

需要一个明确的「鱼主动发言写入」通道，例如：

`POST /dsh-fish-world/session/append`
{ sessionId, role:'assistant', text, proactive:true }

并且该接口要落到真实会话记录（刷新仍在），不是只写前端缓存。

## 本轮做了什么

- `activity` 增加 `platform:'app'` 与 `kind:'poke'`。
- `AvatarTap` 在 20s 缓存未命中时记 `actor:'owner'` 的 poke。
- 没有在 Flutter 侧伪造对话消息，也没有假装刷新后还在。

## 未验证

- 戳头像 → 对话新增一条鱼主动发言：等桥补写接口后再接。
- 她回的那句同步记 `actor:'fish'`：同上，等写接口拿到原文后再记。
