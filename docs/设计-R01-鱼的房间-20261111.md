## 二、渲染选型

选 **B 静态图 + 代码 hotspot 叠加**：

- 底图：`ui/room.png`，`BoxFit.contain`，不改图。
- 交互：`Stack` + 归一化坐标（0–1）的透明 hotspot 按钮，Tab 顺序按视觉从左到右、从上到下。
- 数据驱动变化：只叠 UI 层，不拆图：
  - 台灯：`mood >= 70` 时叠暖光；低于 40 冷光。
  - 显示器：叠最近一条互动文字（最多两行）。
  - 照片墙：待处理 > 0 时挂红色数字角标。
  - 日记：今天有日记时桌面叠一本摊开的小色块。
- 不选 CustomPaint 自绘：重画房间成本高、没有美术收益。
- 不选分层 sprite：PNG 是单层，拆层要先评估透明通道；A 档不做。

**缺口**：参考图没有门/信箱，所以“门口信箱=请求”无法字面实现。A 档建议用右侧照片墙当请求入口，文案标“信箱 · 请求”；若必须门口信箱，需要补一张小信箱素材。

## 三、与「鱼的状态」页的关系

建议 **并存**：

- 房间 = 入口 + 一眼看到状态；点物件跳详情。
- 状态页 = 详细读数；不重复放房间。
- 主人可拍板是否后续用房间取代状态页。

## 四、A 档范围

- 静态房间 + 真读数 + 5 个可点入口。
- 数据驱动只做台灯 / 显示器 / 请求角标 / 日记本。
- 键盘：Tab 到热点，方向键在热点间移动，Enter 进入；写进快捷键表。
- 不做 WASD、家具布置、成就、循环动画。
