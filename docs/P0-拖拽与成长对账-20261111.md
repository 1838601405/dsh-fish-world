## 2. Tooltip 残留

- 拖拽把手与记忆 resize 把手原来用 `Tooltip`。页面 dispose 时 Flutter 的 Tooltip overlay
  可能还挂在根 Overlay 上，和拖拽同族。
- 已改：两处 `Tooltip` → `Semantics(label: ...)`，不再创建 hover 浮层。
- 其它功能性 Tooltip（按钮提示）保留。

## 3. 拖拽幽灵卡

根因（已验证代码路径）：
- `_BentoSlot` 用 `Draggable`，feedback 由 root `Overlay` 承载。
- 拖起后切页，旧页 `_BentoSlotState` 被 dispose，但 `Draggable` 的 drag avatar
  由 Overlay 持有，直到 pointer up 才移除 ⇒ 新页面看到幽灵卡。
- Flutter 没有公开的 `Draggable.cancel()`；要彻底修得改成受控 OverlayEntry
  （自己登记/销毁）或给页面套独立 Overlay。未在本批假装修好。
