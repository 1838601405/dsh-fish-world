# 键盘 · 快捷键（全站一份）

> 2026-11-11。每页交付必须附「操作 × 鼠标 / 键盘 / 两者」表。出现「仅鼠标」行 = 该页不过。

## 鱼的日记

| 操作 | 鼠标 | 键盘 | 备注 |
|---|---|---|---|
| 选日期 | 点格子 | Tab 到格子 + 方向键换日 + Enter | 格子可聚焦，2px primary 焦点环 |
| 上/下月 | 点箭头 | Tab 到箭头 + Enter | IconButton 原生可聚焦 |
| 今天 / 全部 | 点按钮 | Tab + Enter | TextButton 原生可聚焦 |
| 看当天日记 | 自动 | 选日期后自动 | 同一条数据链 |
| 留批语 | 点输入框 | Tab 到输入框 + 输入 + Enter | 同现有输入框 |
| 批准 / 退回 | 点按钮 | Tab + Enter | 同现有 TextButton |

## 鱼的收藏

| 操作 | 鼠标 | 键盘 | 备注 |
|---|---|---|---|
| 选标签 | 点 chip | Tab 到 chip + 左右方向键 + Enter | chip 聚焦有 focusColor |
| 网格移动 | 点图 | Tab 进网格 + 上下左右方向键 | 2px primary 焦点环 |
| 改名 / 标签 / 回收站 | 右键 / hover 图标 | 焦点图块上 Shift+F10 / 菜单键开同一菜单；E 改名 | Esc 关菜单（Flutter 默认） |
