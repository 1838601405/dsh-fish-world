## 横幅盘点

实际只有 4 个页面传 `bannerText`：

1. 鱼的请求
2. 鱼的收藏
3. 鱼的设定
4. 鱼的状态

其余页面走 `fishReadonlyHint` 默认值或根本没有横幅。
`fishReadonlyHint` 定义在 `fish_common.dart L10`，几乎没有页面显式使用。

## 结论

- 不是“横幅多余”，是同一件事五种说法、六种页面没说。
- 统一方案按交接单：
  - 可写页：删整页横幅 → 分区标题右侧「可写」pill + 写按钮旁 10px 小字
  - 只读页：标题右侧「只读」pill
  - 混合页：分区各自标
  - 删除 `FishReadonlyBanner` / `fishReadonlyHint` / `FishPageLayout.bannerText`
- 本轮只交事实表，不改代码。
